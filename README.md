## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save, then wait for GitHub Pages to finish deploying.
6. GitHub will display the published website address in the Pages settings.

## AI connection status
The current website is a static front end. The Prompt Builder improves text locally; it is **not a live AI chat** yet.

To add a live AI assistant, connect a backend service and store the provider API key as a server-side hosting secret. Never put API keys, passwords, or tokens in `index.html`, browser JavaScript, or a public repository.
